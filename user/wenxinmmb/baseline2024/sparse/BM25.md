# BM25 baseline

This readme contains instructions for reproducing a BM25 run using pyserini for the TREC track on tip-of-the-tongue (ToT) 
retrieval. You can view [Guidelines](https://trec-tot.github.io/guidelines) for more details.

## Baseline
### To run the BM25 baseline for 2025 dataset:
```
DATA_PATH= ## enter path to 2025 data ###
cd sparse # make sure you are in the sparse directory
## for training set
python bm25.py --index_name bm25 --index_path ./anserini_indicies/2025 \
               --data_path $DATA_PATH \
               --param_k1 1.0 --param_b 1.0 \
               --field text --splits train-2025 \
               --run ./runs/2025/bm25/train.run --run_format trec_eval --run_id baseline_bm25 \
               --negatives_out ./bm25_negatives/2025/train-negatives.json

## for dev1 set
python bm25.py --index_name bm25 --index_path ./anserini_indicies/2025 \
               --data_path $DATA_PATH \
               --param_k1 1.0 --param_b 1.0 \
               --field text --splits dev1-2025 \
               --run ./runs/2025/bm25/dev1.run --run_format trec_eval --run_id baseline_bm25 \
               --negatives_out ./bm25_negatives/2025/dev1-negatives.json

## for dev2 set
python bm25.py --index_name bm25 --index_path ./anserini_indicies/2025 \
               --data_path $DATA_PATH \
               --param_k1 1.0 --param_b 1.0 \
               --field text --splits dev2-2025 \
               --run ./runs/2025/bm25/dev2.run --run_format trec_eval --run_id baseline_bm25 \
               --negatives_out ./bm25_negatives/2025/dev2-negatives.json

## for dev3 set
python bm25.py --index_name bm25 --index_path ./anserini_indicies/2025 \
               --data_path $DATA_PATH \
               --param_k1 1.0 --param_b 1.0 \
               --field text --splits dev3-2025 \
               --run ./runs/2025/bm25/dev3.run --run_format trec_eval --run_id baseline_bm25 \
               --negatives_out ./bm25_negatives/2025/dev3-negatives.json

## (once test split is released)
python bm25.py --index_name bm25 --index_path ./anserini_indicies/2025 \
               --data_path $DATA_PATH \
               --param_k1 1.0 --param_b 1.0 \
               --field text --splits test-2025 \
               --run ./runs/2025/bm25/test.run --run_format trec_eval --run_id baseline_bm25 
```

## Description
The script produces the following files
1. BM25 index and stored them in the ./anserini_indicies directory. 
2. An intermediate directory ./anserini_docs which contains the documents used to create the index. 
3. The run files in the ./runs/{2025/2024}/bm25 directory, which are in TREC format and can be used for evaluation.
4. The negative samples for training in the ./bm25_negatives directory, which are in JSON format.

Note: when there is no index present in "./anserini_indicies "directory, the script will create the index from the corpus from scratch. If the index already exists, it will skip the indexing step and directly use the existing index.

## Evaluation
You can evaluate either using pytrec_eval (included in the script above), or use `trec_eval`:

To download trec_eval
```
brew install trec_eval
```

```
# train
trec_eval -m ndcg_cut.10,1000 -m recall.1000  -m recip_rank $DATA_PATH/train-2024/qrel.txt ./runs/bm25/train.run
    recip_rank            	all	0.0530
    recall_1000           	all	0.3400
    ndcg_cut_10           	all	0.0610
    ndcg_cut_1000         	all	0.0968


# dev1
trec_eval -m ndcg_cut.10,1000 -m recall.1000  -m recip_rank $DATA_PATH/dev1-2024/qrel.txt ./runs/bm25/dev1.run
```
